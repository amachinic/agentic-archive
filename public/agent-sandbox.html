05

A full run

one job end to end · find → arrange → file · played in the app, not in a mockup

One job, start to finish, in the running app below: find the photography, arrange it by colour, file it as a folder. The demo types into the real composer and the real agent answers — the tool calls, the counts and the field re-forming are its own. At the end it presses Accept on the proposal, so the folder it names is really created — through the app’s own button, the only door that writes — and then removes it again, because a simulation should hand the library back the way it found it.
